# Sitio demo para propuesta (listo)
- index.html (banner + carrusel + reseñas + CTAs + botones flotantes + chat)
- terminos.html / privacidad.html
- assets/css/style.css
- assets/js/main.js

## Personalización rápida
1) Cambia teléfono, email y WhatsApp en index.html (busca 'wa.me').
2) Reemplaza el logo: assets/img/logo.svg
3) Reemplaza slides: assets/img/slider/slide-*.svg

## Nota
Este demo es ideal para presentar la propuesta. Para producción, reemplaza textos legales por los del negocio.
